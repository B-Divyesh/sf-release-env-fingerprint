# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - 2026-08-28

### Added

- Signed, privacy-preserving environment capture.
- Drift comparison with human-readable and JSON output.
- Required-name, required-prefix, endpoint-host, and non-secret hash policies.
- Static documentation and interactive local-only comparison demo.

### Fixed

- Keep primary content and install actions inside 390 px and 200% reflow viewports.
- Precache hashed site assets with content-versioned PWA caches and network-first navigation updates.
- Preserve keyboard focus after comparisons and provide 44 px mobile navigation targets.
- Align the brand's accessible name with its visible label and cache hashed assets immutably.
